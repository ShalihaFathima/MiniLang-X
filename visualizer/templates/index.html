Separated by whitespace or compact terminals matching grammar tokens (e.g. id + id * id).
Bottom-Up LR Parsing Principles
SLR(1) Constructs LR(0) items. Uses FOLLOW(A) sets for reduce actions. Simple but susceptible to false shift/reduce conflicts.
CLR(1) Canonical LR(1) items carry specific lookahead tokens [A -> α • β, a]. Conflict-free for all LR(1) grammars, but has more states.
LALR(1) Merges CLR(1) states sharing identical LR(0) cores, combining their lookaheads. Same state count as SLR(1); may introduce reduce/reduce conflicts.
